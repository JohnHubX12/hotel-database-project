# hotel-database-project

Academic project focused on the design and implementation of a relational
database for a hotel management system.

## Project Overview

The database supports the management of:

- Customers
- Reservations
- Rooms
- Hotel services
- Payments
- Customer reviews

## Database Design

The project includes:

- Entity-Relationship diagram
- Relational database schema
- Primary and foreign keys
- Table relationships
- SQL table creation
- Example queries and screenshots

## Technologies

- MySQL
- SQL
- Relational Database Design
